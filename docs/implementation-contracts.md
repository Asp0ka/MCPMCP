# Shared implementation contracts

Package dev.mcpmcp.forge (version module), dev.mcpmcp.core, dev.mcpmcp.api.
Java17 official Minecraft1.20.1 mappings, Forge47.4.28. No JEI. Use Gson JsonObject DTO.

Parent owns Runtime.java, Mcpmcp.java, Configuration.java, Actions.java, ContainerSessions.java, build files, core/. Avoid modifying these from other tasks.

core.Jsons: static JsonObject obj(Object... pairs), error(String code), static String str(JsonObject,String,String fallback), int integer(JsonObject,String,int fallback), double number(JsonObject,String,double fallback), boolean bool(JsonObject,String,boolean fallback), JsonObject object(JsonObject,String), JsonArray array(JsonObject,String). Throws IllegalArgumentException for wrong types. obj uses Gson.toJsonTree.

Runtime: public static Configuration config(); public static JsonObject status(); public static JsonObject execute(String action,JsonObject args,String id); public static JsonObject call(String method,JsonObject args). All handlers on client thread. Configuration has public fields String mode="NORMAL", transport="MIXED"; boolean debug=false, trustJavaPlugins=false; int port=5007; String token; int scanBudget=4096. Config gameDir from FMLPaths.GAMEDIR.get(). No plugin code needs these fields, use context.

Observations.read(String kind, JsonObject args): JsonObject envelope {data,source,scope,observed_at,complete,truncated,world_epoch} or {error,reason}. Client-thread only, kinds player/inventory/item/equipment/state/blocks/entities/chunks/structures/mods/paths/recipes/chat/screen/screenshot. Split UiActions, RecipeService, ChatLog as helpful; names not bound to parent beyond Observations.read and UiActions.execute. Use bounded scan pages, honest unavailable server data. Runtime injects world_epoch if missing. Long scan per-request at most min(4096,config.scanBudget), return cursor/offset, no unbounded copy.

UiActions.execute(String action,JsonObject args): returns JsonObject result; action names ui.click/ui.key/ui.mouse/ui.text/ui.focus/ui.scroll/world.create/world.join/world.leave/world.open_lan/screenshot. Never arbitrary reflective screen invocation. UI query UiActions.read(JsonObject args), screenshot result explicit mime/base64 and bounds. Use Minecraft keyboard/mouse handlers or vanilla widgets safely. ui.text can target EditBox; only manipulate explicit selected field, preserve focus.

ChatLog.read(JsonObject args), ChatLog.record(Component, String kind), initialized Forge client message events. Keep bounded sequence history; no secrets. RecipeService.read(JsonObject args) for vanilla recipes; runtime returns provider vanilla.

PluginManager(Path root): JsonObject reload(); JsonObject status(); JsonObject describe(String id); JsonObject actions(); boolean hasAction(String name); JsonObject execute(String name,JsonObject args); Optional<JsonObject> observe(String kind,JsonObject args). Main thread. Initialized by parent with GAME_DIR/MCPMCP-Plugin. Can use PluginContext interface, no Runtime mandatory dependency. Constructor takes exact plugin root; bind facade via setContext(PluginContext). Entire declarative revision reload atomically; no classload on manifest inspection. Java needs local config trustJavaPlugins and game restart. Observe errors no propagation to other modules.

PacketService: static JsonObject read(String kind,JsonObject args) kinds packets/packet/packet_capture; static JsonObject execute(String action,JsonObject args) action names packet.capture_start/packet.capture_stop/packet.send; static void record(Object packet,String direction); static void connectionChanged(). PluginManager can invoke PacketService via PluginContext.execute('packet.send',args) through parent after policy. Never send arbitrary byte arrays unbound to a discovered class/channel. Reuse existing connection; cap capture.

API McpmcpPlugin: String id(); void register(PluginContext context). PluginContext: void action(String name,JsonObject schema,String transport,String permission,Handler handler); void observer(String kind,int priority,Handler handler); JsonObject execute(String action,JsonObject args); JsonObject observe(String kind,JsonObject args). Handler JsonObject call(JsonObject args) throws Exception. JSON declaration plugins can declare actions {name,packet:{...},input_schema,transport,permission,preconditions,verify}; full target hash, mod_id/version, mc/loader/api. Permission enforced centrally; plugin MD never grants authority. Shared JSON schema validation must reject unknown keys and nonfinite numbers, bound recursion. No arbitrary files except plugin root accepted.

Build invocation via powershell Build.ps1 -Offline or version Gradle with local JDK17. Parent integrates/builds; implementers can use javap via old tooling without copying implementation. Do not run Gradle concurrently. Do not commit or operate game in subagent tasks. Write tests before implementation and record RED/GREEN outputs in task report.
