# 插件设置列表与界面本地化

用户要求设置界面显示插件、目标模组安装/版本一致状态，并允许版本不匹配强制加载；英文/简体中文随游戏语言自动切换。沿用此前自主实施授权，不追加审批。

采用现有设置页增加“插件”入口和原生可滚动列表，而非挤入原设置按钮或自建外部页面。每个插件显示id/目标模组、已安装版本、manifest target_version（可选）、SHA256匹配、活动/强制/缺失/平台不符状态，操作区允许刷新和本地强制加载/撤销。未声明版本明确显示未指定，不能把hash相同当成version显式相同。

强制加载只覆盖已安装模组的版本/hash兼容门禁，不绕过缺少模组、平台/API/schema、封包方向/权限或Java信任。持久化同一次manifest+实际mod版本/hash的绑定授权，改变声明或目标JAR则失效，避免写插件文本自行获取授权。Java仍冷加载，界面说明需重启；撤销已加载Java也需重启。MCP不提供修改此授权的入口，保护插件设置页与原设置页一致。

所有本模组GUI标签/模式/执行方式/状态/确认提示使用Component.translatable与en_us/zh_cn资源，不覆盖语言设置，不翻译机器JSON字段或协议错误码。英文为其他语言回退。无关行为与布局保持。

验收：纯Java兼容与授权绑定矩阵、manifest旧格式兼容、Config保存加载；两份语言键一致与实际使用键覆盖；完整build；专用客户端真实两语言界面、列表、强制/撤销/缺模组拒绝/刷新与重启持久性。输出更新JAR/提交与记录。
