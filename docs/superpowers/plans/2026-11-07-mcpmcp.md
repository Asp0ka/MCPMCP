# MCP Minecraft Plus Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox syntax. User authorized autonomous execution and no intermediate approvals.

**Goal:** Deliver the requested extensible client automation mod, MCP bridge, skill, and verified Forge1.20.1 build.
**Architecture:** Platform-independent policy/jobs/plugin contracts, Forge-specific game modules, bounded loopback HTTP and stdio MCP. Packet-first actions with explicit simulation fallback policies and stateful container leases.
**Tech Stack:** Java17, Gradle8.8, Forge47.4.28, Gson, Python standard library.
**Spec:** docs/superpowers/specs/2026-11-07-mcpmcp-design.md

## Global Constraints
- Names MCP Minecraft Plus / MCPMCP; dedicated test instance 1.20.1-Forge_47.4.28-test only.
- No JEI/REI dependency; no arbitrary external file modification tools; no fabricated unavailable world data.
- Hot declarations, cold trusted Java plugin reload, revision pinning and state verification.
- UI/main-menu availability; NORMAL/HACK/CHEAT/HACK_CHEAT and PACKET/SIMULATE/MIXED enforced centrally.
- Per-task tests first then implementation; game writes require exact target read-back.

## Review Focus
- Menu opens asynchronously or is manually replaced: do not click another menu or leak carried items.
- Cancellation and world change: stop transient use, movement and GUI/session ownership.
- Unknown nested JSON, packet schemas, paths/symlinks and plugin hash mismatch: reject before side effects.
- Large area, missing chunks, pause/main menu: bounded work with honest completeness.
- Plugin Java trust, data provenance, replay/delivery ambiguity: no file-policy or mode bypass.
