# 0.1.1 插件列表与界面多语言

## 使用

Forge“Mod”列表选择 MCP Minecraft Plus → 配置 → 插件列表。原生可滚动列表逐条显示插件id、对应mod id、是否安装、目标与已安装版本、版本检查、JAR指纹检查和加载状态。没有target_version的旧manifest显示“未指定”。

选择不匹配条目可“强制加载”，确认后保存；“取消强制”撤销。缺少对应模组时按钮禁用。版本强制只处理兼容性，不跳过平台/API/schema/权限/Java信任。Java适配器只能冷加载和重启卸载。

设置/列表/确认框的英文和简体中文使用游戏标准语言资源，切换游戏语言后生效。英文作为其它语言回退，机器字段、插件id与协议错误码不翻译。

## 验证结果

完整Build.ps1离线构建退出0：Core56、兼容矩阵12、插件声明16、manager21、UI安全31、观测44+4、HTTP回环、配置保存/加载/撤销/非法授权测试、PluginStep/Reload，以及Python15项均通过。不将不同粒度重复运行加总为覆盖率；Windows symlink创建权限不足仍明确跳过。

实际专用客户端（1.20.1/Forge47.4.28）验证：

- 中文设置/插件页/确认框；切游戏语言为English (US)后对应界面全部英文，再恢复简体中文。
- 目标Minecraft1.20.1一致、1.19.4不一致、未声明目标版本、缺模组四类显示；真实Baritone安装1.10.5对声明1.10.4版本不符且JAR hash一致。
- 通过本地窗口点击强制加载，状态forced，取消后target_version_mismatch；重启客户端后授权仍保留。
- 已打开确认框返回后保留所选行及滚动位置；缺模组强制按钮禁用。
- MCP对设置/插件列表/强制确认页的ui.click拒绝，未新增远程自授权入口。
- 注入“授权撤销+其它插件损坏”，旧强制动作返回plugin_override_revoked；修复无关声明后自动重试重载，旧动作移除。
- 空列表提示与禁用按钮；401×301 GUI窄窗口，长id/长版本保持行内裁剪、悬停可读完整信息；中英文截图无可见重叠/未翻译key。

Focused独立审查发现1项重要、2项次要，均处理：撤销/重载失败一致性、已加载Java文件消失仍提示重启、目标JAR不可识别单独原因。对应回归及全套测试通过。Java代码仍不是同JVM强沙箱。

证据：`evidence/plugin-settings-0.1.1/` 的build-output、真实事件摘录、两语言/窄窗/空列表/确认截图与final-state。事件摘录仅从实际日志按本功能筛选，不是所有窗口点击的完整转录；OS本地点击结果由实时读取与截图核对。

## 收尾

JAR已安装专用实例且与构建hash一致。测试插件移至工程.local备份，未更改其它模组/配方；本模组pluginOverrides为空。游戏语言恢复简体中文，NORMAL+MIXED、DEBUG关闭、Java不信任；客户端停主菜单。旧0.1.0验收保留为历史证据，不以此替代本次验证。
